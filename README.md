# Project_0_F26
Introduction to Github

In this lab, you will be learning about git and some of the features of git and GitHub. A part of the lab will be to clone this repository to your own system and and then make changes to the repository. (Work on the project in your cloned repository; do not work in this repository). Once you have cloned the repository project, you are to solve the programming project using this cloned repository. The attached simple source file print_random_string.c is to be modified by you to include a function that implements the rand_string() function. See the instructions in the GitHW file.  

In addition to the project source code, the repository includes the project description with activities to be carried out.
